1 - Requisitos

    Opção 1:
        MySQL 8.x.x
        Apache2 2.x
        PHP 7.x

    Opção 2:
        Xampp v3.x.x


2 - Instalação

    2.1 - Preparação do banco:
        Após instalar o MySQL e definir uma senha para o root 
        (senha que será usada no arquivo de conexão do sistema 'ramais'),
        criar um banco com o nome 'listagemDeRamais' e executar o script de backup 
        'listagemDeRamais.sql' que se econtra em ramais/backup-do-banco/ para criação 
        e pupulação das tabelas (caso haja dados prévios).

    2.2 - Usando MySQL, Apache2 e PHP instalados separadamente:
            Após a preparação dos requisitos, Copiar a pasta 'ramais' para a pasta configurada no Apache2.

    2.3 - Usando o Xampp:
            Copiar a pasta 'ramais' para Xampp/htdocs.


3 - Possíveis erros e soluções na instação do MySQL, Apache2 e PHP
